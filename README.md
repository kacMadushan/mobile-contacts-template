# Contacts Web Template

Welcome to the official repository for the contacts web template. This project is designed to provide information about mobile contact app, showcase it's features, and offer a seamless user experience for visit and learn more about this web template. This template designed by HTML and TailwindCSS.

![image alt](https://github.com/kacMadushan/mobile-contacts-template/blob/b5e0b452d0fe5cd039934ea1d8ee546665f1ddaa/screen.png)

## Tech Stack
    - HTML
    - Tailwind CSS - (v4.1)
    - Prettier

#### Prerequisites

Make sure you have the following installed on your machine:
    - Git
    - Node Js
    - npm (Node Package Manager)
    - Live Server

#### Installation

Install the project dependencies using npm:

```bash
git clone git@github.com:kacMadushan/mobile-contacts-template.git  && cd mobile-contacts-template
npm install
npm run dev
```
